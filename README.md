# RDFtoCSV-JAR
To use this .jar file, download it and then use in your command line like this:
```shell
java -jar RDFtoCSV.jar -f <Your-RDF-File-Name>  
```
for example
```shell
java -jar RDFtoCSV.jar -f testingInput.ttl
```

Note that the RDFtoCSV.jar and <Your-RDF-File-Name> have to be both in the same directory when executing the command.

For more detailed documentation, visit one or all of these:

* [rdf-to-csv.github.io - web application](https://github.com/LadyMalande/rdf-to-csv.github.io)
* [RDFtoCSVWAPI - web service](https://github.com/LadyMalande/RDFtoCSVWAPI)
* [RDFtoCSV - library](https://github.com/LadyMalande/RDFtoCSV)

For all functional purposes, the two .jar archives in this repository are the same. 
You can use them interchangeably.
